# .github

`matsukawa-group` の Organization 全体に適用する設定・テンプレートを管理するリポジトリです．

| ファイル | 役割 |
| ---- | ---- |
| [`profile/README.md`](profile/README.md) | Organization のページに表示される公開用のプロフィール |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | 独自のテンプレートを持たない全リポジトリに適用される PR テンプレート |

メンバー向けのプロフィール（内部ポータル）は `.github-private` リポジトリの `profile/README.md` で管理しています．
公開用のプロフィールと書式を揃えて編集してください．
